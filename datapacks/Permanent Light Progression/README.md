# Permanent Light Progression

Minecraft 1.21.1 datapack containing the 22 approved permanent-light recipe changes.

Recipes use the original namespaces and recipe IDs, preserving existing outputs.
The dimmer keeps its redstone torch and adds a regular torch. The tooth lantern
keeps its prismarine crystal and adds a regular lantern. Natural blocks and
unapproved light families are unchanged.

This modpack deploys this unpacked folder (with pack.mcmeta at its root) in the
base datapacks directory. Paxi's base-folder loading option enables it for all
worlds automatically. Do not also deploy a ZIP under config/paxi/datapacks or
install a duplicate copy in a world's datapacks folder.

Requires the pack's content mods and Flimsy Torches for the intended progression.
